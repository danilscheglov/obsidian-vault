# Obsidian Vault

Личное хранилище знаний на базе [Obsidian](https://obsidian.md/), организованное с использованием метода PARA и карт содержания (Maps of Content, MOC).

## Структура хранилища

Заметки организованы по методу PARA. Нумерация папок помогает сохранять порядок разделов.

| Папка         | Назначение                                                  |
| ------------- | ----------------------------------------------------------- |
| `0 Inbox`     | Входящие заметки, идеи и материалы, которые нужно разобрать |
| `1 Projects`  | Активные проекты с конкретными целями и результатами        |
| `2 Areas`     | Постоянные сферы ответственности и интересов                |
| `3 Resources` | Знания, справочные материалы и конспекты                    |
| `4 Archives`  | Завершённые проекты и неактуальные материалы                |
| `5 Meta`      | Индекс хранилища, шаблоны и правила организации             |

## Принципы организации

- **PARA** — организация материалов в зависимости от их назначения и актуальности.
- **MOC (Maps of Content)** — карты содержания, объединяющие связанные заметки и упрощающие навигацию по темам.
- **Внутренние ссылки** — связи между заметками, позволяющие переходить от одной идеи к другой.
- **Inbox** — единое место для быстрого сохранения новых идей и материалов с последующей обработкой.
## Назначение репозитория

Репозиторий предназначен для личного использования. Его структура, содержание могут меняться по мере развития хранилища.
